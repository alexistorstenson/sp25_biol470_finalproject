# sp25_biol470_finalproject

## Atmospheric Analysis of Folly Beach Conditions During the COVID-19 Pandemic

## Objective
#' To analyze the metereological differences in the Folly Beach area during the 
#' 2020 COVID-19 outbreak and the immediate prior years and determine if this
#' ultimately had any tangible effect on the climate. 

## Dependencies
#' The following libraries need to be installed to run the program:
#' - dplyr
#' - ggplot2
#' - patchwork

## Data
#' The necessary data can be found in the data folder in .csv format in 3 files.
#' It was collected by NOAA's National Buoy Data Center at Station FBIS1 on
#' Folly Island, South Carolina from 2018 to 2020.

## Files
#' The main file to run the project is airtemp_dewp_plots.R

## Analysis
#' It was determined that while the COVID-19 Pandemic did generally cause a 
#' slight change in the climate temporarily due to decreased greenhouse gas
#' emmisions during the lockdown, this ultimately had no bearing on the overall
#' temperatures in the Folly Beach area, and did not effect the dew point and
#' humidity in a tangible way.
